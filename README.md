# Learn Linux

My personal notes, scripts, and mini projects while learning Linux, networking, shell scripting, and Git for DevOps, published as a searchable website.

**Website:** https://gbilgi.github.io/learn-linux/

## Goal
Become confident working on Linux from the command line, automate everyday tasks with shell scripts, and understand the networking and Git workflows used in DevOps, with every topic documented in my own words and backed by commands I have actually run.

## Roadmap
- [ ] 1. Linux Fundamentals: introduction, file management, users and permissions, process management
- [ ] 2. Text Processing: text processing, advanced text processing and scheduling
- [ ] 3. Networking: introduction, OSI model, devices, networking in Linux, networking security (DevSecOps)
- [ ] 4. Shell Scripting: introduction, fundamentals, walk through
- [ ] 5. Shell Scripting for DevOps: file, process and filesystem management, backup, networking, AI-assisted scripting
- [ ] 6. Git: introduction, Git in DevOps (hooks, pull requests, branching)

## Repository layout
- `docs/` explanations (published as the website)
- `code/` shell scripts and command examples that mirror `docs/`
- `projects/` mini projects that apply what I learn

## Conventions
- Examples use documentation-only addresses (such as `192.0.2.10` and `10.0.0.x`) and made-up hostnames.
- No real credentials, work configurations, or device details belong in this repository.
- Risky commands are practised in a disposable container or VM, not on my main system.

## Working on it locally
Activate the `docs` conda environment, run `mkdocs serve`, and open http://127.0.0.1:8000.
